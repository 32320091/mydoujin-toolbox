# 我的同人｜篡改猴腳本

給 [我的同人](https://mydoujin.online/) 用的篡改猴（Tampermonkey）腳本。

| 腳本 | 檔案 |
|---|---|
| **工具箱（整合版，推薦）** | `mydoujin-toolbox.user.js` |
| 戰報統計面板 | `mydoujin-battle-stats.user.js` |
| 戰報逐行播放 | `mydoujin-battle-playback.user.js` |
| 角色查詢 | `mydoujin-character-finder.user.js` |
| Boss 冷卻倒數 | `mydoujin-boss-cooldown.user.js` |

> 工具箱已經包含下面四個功能，**裝了工具箱就不要再裝單獨的版本**（否則同一個功能會跑兩次）。

## 工具箱

把戰報統計、戰報逐行播放、Boss 冷卻倒數、角色查詢整合成一個插件。

- 左下角的圓形圖示按鈕：列出每個功能的一行說明與開關。
- 每個功能都有開關，**切換立即生效、不用重新整理**；關掉時畫面馬上恢復成遊戲原本的樣子。開關存在你自己的瀏覽器裡。
- 「全部開啟」一鍵恢復。
- 各功能的詳細說明見下方各節。

## 戰報統計面板

打開戰報頁時，在右下角顯示統計面板。

### 功能
- 玩家與 BOSS 的造成傷害、幸運傷害、總計傷害、承受傷害
- 回復血量、回復 SP、每人爆擊率
- 燒掉的生命上限、角色特殊迴避、中毒／出血／凍傷等異常狀態與反傷
- 標題列「簡易／詳細」切換（會記住）：簡易只看名次、總計傷害佔比、承受、回血、爆擊率；詳細是全部欄位，點角色看細項
- 「顯示」切換：全部／玩家／BOSS（對手）分開看；「⤢ 自動縮放」：戰報太長時先收緊行距、再整個等比縮小，讓一個視窗看完（最小 50%，可關閉，會記住）
- 頂部摘要：我方總傷害、MVP（綜合貢獻：各項佔全隊比例的加權平均，權重 輸出×1 > 補隊友×0.5 > 承受傷害×0.25 = 回SP×0.25 > 自回×0.1；補隊友＝能補隊友的治療技能：番茄湯、小黃金樹、緊急包紮、治癒之鎖、治癒魔術…補到自己也算；自回＝只能補自己的吸血、自補；滑鼠移上去看全隊排名）、最佳坦克、最佳奶媽（只看治療技能）；勝負以顏色標籤顯示，前三名有金銀銅名次徽章
- 收合時標題列只留「戰報統計、＋/－、✕」，展開後才顯示戰報編號與時間
- 展開時可拖曳右下角調整面板大小（會記住；雙擊右下角或按「⤢ 自動縮放」恢復預設大小）
- 名字前面帶一整句台詞的（例如「…門縫裡鑽了出來。懲戒鳥」）只顯示句號後面的名字，滑鼠移上去看完整名字；名字太長會自動換行，不會把數字欄擠出畫面
- 手機直拿（畫面寬 640px 以下）自動改成底部抽屜＋角色卡片，不用左右滑；轉橫或電腦維持表格
- 召喚物（分身、寶月夜宵的四隻、十二神將、各樓層 BOSS 叫出來的小兵…）自動抓名字：看牠之後被打、出手、倒下的紀錄判斷，不靠固定名單
- 西米專屬：番茄湯總回復（立即＋持續，逐位隊友，含西米倒下後繼續跳的）、臭臭茶放屁傷害（逐位喝茶的隊友）、回收桶紀錄

### 隱私
- 腳本只在 `mydoujin.online` 上執行。
- 讀取戰報時，使用你自己瀏覽器裡的登入狀態，向遊戲官方後端 `mydoujin-backend.onrender.com` 讀取戰報資料。
- 不會把任何資料送到其他網站；統計結果與圖鑑只存在你自己的瀏覽器（localStorage）。

## 戰報逐行播放

Boss 挑戰、玩家切磋／茶渡、事件遭遇戰、戰報頁回放時，戰鬥過程一行一行出現，看到最後一行才知道結果。

### 功能
- 戰鬥過程逐行出現，上方顯示目前播到第幾行（不顯示總行數），可按「跳過，直接看結果」
- 播放完之前，蓋住勝利／失敗／平手標記、死亡標記、頂部死亡橫幅，以及隊伍的存活／死亡狀態
- 事件結算視窗的「遭遇戰鬥！(勝利／失敗／平手)」改成不寫結果，勝負等戰報播完才知道
- 同時裝了「戰報統計面板」時，播放中面板不顯示任何數字與勝負，只顯示「⏳ 播放中」（收合、縮成小按鈕時也一樣；不顯示總行數，免得猜出哪一行結束），播完才出現統計
- 播完可「重播」
- 每一行後面顯示這一行被打／被補／閃開攻擊的人剩多少血（名字＋血條＋剩餘/上限）；群體治療每個被補的人各自一行、各自顯示
- 「⚙ 戰報播放」設定：
  - 逐行播放／直接顯示結果
  - 是否顯示每行剩餘血量
  - 每行間隔秒數
  - 播放時自動捲到最新一行
- 設定按鈕位置：戰報頁在「戰鬥過程」旁；Boss 頁在隊伍代碼那一列；玩家頁在「友好切磋／茶渡」上方

### 隱私
- 腳本只在 `mydoujin.online` 上執行。
- 只觀察遊戲本身的挑戰／切磋／戰報請求來決定何時開始播放，並沿用遊戲拿到的戰報資料計算剩餘血量。
- Boss 挑戰、切磋／茶渡的回傳資料裡沒有角色血量上限時，會用你自己瀏覽器裡的登入狀態，向遊戲官方後端 `mydoujin-backend.onrender.com` 讀一次該場戰報（跟戰報頁讀的是同一份）。
- 不會把任何資料送到其他網站。
- 設定只存在你自己的瀏覽器（localStorage）。

## 角色查詢

依角色查出誰在用這個角色，可在「玩家列表」與 Boss 頁的「選擇助戰」使用。

### 功能
- 玩家列表：標題下方多一個「🔎 依角色查玩家」區塊，按「掃描全部玩家」讀完整份玩家列表後，可用角色下拉選單、角色小標籤或關鍵字（角色／稱號／暱稱）篩選，列出暱稱、等級、角色（稱號）、目前／最高樓層、死亡狀態，點暱稱進玩家頁
- 選擇助戰：搜尋框下方多一個「🔎 依角色找助戰」區塊，按「掃描助戰名單」讀完這個樓層區間所有可借的人，依角色篩選並顯示等級、樓層與九項能力值；按「帶入」會把暱稱填進遊戲的搜尋框並搜尋，再按遊戲自己的「選擇」即可
- 選擇助戰預設只看 Lv100 以上（最低欄位預先填 100，可自行修改或清空）
- 兩個區塊都能用「Lv 最低～最高」篩等級（只填一邊＝以上／以下，填反會自動對調）；角色小標籤的人數會跟著等級範圍變
- 兩個區塊都可以點標題列收起／展開（各自記住）；手機自動改成直排

### 伺服器負擔
- 只有按「掃描」時才會讀資料，不會自動重複讀取。
- 玩家列表一頁 50 人，八百多人約 17 頁；最多同時 2 個請求，每頁之間稍停。結果存在瀏覽器 30 分鐘內不用重掃。
- 助戰名單一頁 10 人，通常 3～6 頁。

### 隱私
- 腳本只在 `mydoujin.online` 上執行。
- 使用你自己瀏覽器裡的登入狀態，向遊戲官方後端 `mydoujin-backend.onrender.com` 讀取玩家列表與助戰名單（跟遊戲本身讀的是同一份資料）。
- 不會替你選擇助戰或送出任何操作；不會把資料送到其他網站；掃描結果只存在你自己的瀏覽器。

## Boss 冷卻倒數

Boss 頁原本只寫「XX 的 Boss 挑戰冷卻中，還有 N 分鐘」，改成每秒跳動的「還有 M 分 SS 秒」。

### 功能
- 隊伍裡每個人的冷卻都各自倒數到秒。
- 秒數怎麼算：
  - 跟你同場打的人（包含你自己）：用最近一場 Boss 戰報的時間加 30 分鐘，一進頁面就準到秒。
  - 別場打的隊友：先顯示「校正中 ±N 秒」，在分鐘跳號的時間點補查隊伍幾次（每段冷卻最多 8 次），約 5～8 分鐘內收斂到 1 秒左右。
- 冷卻到 0 顯示「已結束 ✅」，並自動按一次遊戲的「刷新」，讓「開始挑戰」解鎖。第一行後面的「⟳ 自動刷新」可以點擊開關。
- 重新整理頁面後，已算出的時間會沿用。

### 伺服器負擔
- 主要讀遊戲自己已經抓的資料；你自己的冷卻另外讀 1 次戰報列表（10 筆）。
- 只有別場隊友校正時才補查隊伍，每段冷卻最多 8 次。

### 隱私
- 只在 `mydoujin.online` 執行，只讀資料，不會替你按「開始挑戰」或送出任何操作；只會在冷卻結束時按「刷新」（可關）。
